# StrengthLog

[![CI](https://img.shields.io/github/actions/workflow/status/apoorvsingh090/strengthlog/ci.yml?branch=main)](https://github.com/apoorvsingh090/strengthlog/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![tests](https://img.shields.io/badge/tests-12%20unit%20tests-brightgreen.svg)](app/src/test)

A local-only Android strength-training tracker: log workouts, build templates, and track your powerlifting level — no account, no internet access, no data leaves your device.

Clones the core of [my.strengthlevel.com](https://my.strengthlevel.com) as a native app.

## Features

- **Workout logging** — exercises, sets, reps, weights, warm-up sets, bodyweight, date/time pickers
- **Templates** — reusable workout templates, start a session in one tap
- **Exercise library** — 160-exercise catalog (seeded on first launch) + custom exercises
- **Reports & charts** — per-exercise history, best sets, estimated 1RM progression
- **Powerlifting level** — squat/bench/deadlift standards with percentile estimate and Wilks score
- **1RM calculator** — Epley and related estimators
- **CSV import/export** — round-trips the app's own format and imports exports from my.strengthlevel.com (weights converted lb→kg automatically)

## Stack

- Kotlin + Jetpack Compose (Material 3)
- Room (local SQLite, schema exported to `app/schemas/`)
- MVVM with `StateFlow`
- Gradle 8.10.2 / AGP 8.7.3 / Kotlin 2.0.21 / Compose BOM 2024.12.01

## Build

```bash
# JDK 17, Android SDK with platform android-35
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 12 unit tests (standards, 1RM, Wilks, CSV)
```

Requires `local.properties` with `sdk.dir=...` (generated by Android Studio, git-ignored).

## CSV format

```
date,title,bodyweight_kg,exercise,set_number,weight_kg,reps,is_warmup,duration_minutes,start_minute,end_minute
```

Also accepts my.strengthlevel.com exports:
`Date Lifted,Exercise,Weight (kg),Weight (lb),Reps,Bodyweight (kg),...` — date format `YYYY-MM-DD` or `DD-MM-YYYY`.

Re-importing the same file is idempotent: imports are skipped by per-workout content fingerprint, never by title.

## Privacy

- No `INTERNET` permission — the app is offline by construction
- Everything lives in `lolmax.db` (Room) on-device
- CSV export writes via the Storage Access Framework to a location you pick
